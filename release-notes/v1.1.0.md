## WhisperLS 1.1.0

This release introduces complete application localization and makes mixed
queue management more flexible and reliable.

### Highlights

- Interface available in Italian, English, French, Spanish, German, and
  Portuguese.
- First-run language selection with flags and an always-accessible selector in
  the top bar.
- Transcription language initially follows the interface language while
  remaining independently configurable.
- Localized console output, status messages, progress, warnings, and errors.
- Queue manager supporting any combination of independent and multipart jobs.
- Animated drag-and-drop reordering constrained to the queue area.
- Custom output name for each job with safe automatic defaults.

### Fixes and improvements

- Multiple tracks now start as separate jobs and are merged only when
  explicitly requested.
- Fixed crashes, first-job overlap, and layout issues in the queue manager.
- Fixed untranslated selector values such as `Automatico` and remaining
  Italian strings in console output.
- Updated documentation for all six supported interface languages.
