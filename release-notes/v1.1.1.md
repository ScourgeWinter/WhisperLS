## WhisperLS 1.1.1

Questa versione corregge il crash all'avvio dell'interfaccia Windows presente
nei pacchetti 1.1.0. La pubblicazione ora include `WhisperLS.pri`, l'indice delle
risorse che contiene le schermate WinUI compilate.

### Correzioni

- Inclusione delle risorse dell'interfaccia nei pacchetti Full, Light e Portable.
- Copia dei file XAML compilati separati nelle pubblicazioni Debug.
- Controllo bloccante nella creazione delle release se l'indice delle risorse
  dell'applicazione è assente o vuoto.

### Verifiche

- Apertura dell'interfaccia verificata localmente nelle build Release e Debug.
- Causa confermata aggiungendo il solo indice mancante al pacchetto 1.1.0.
- 22 test Python superati, inclusi tre test sul controllo del pacchetto.

Per usare la correzione, scarica un pacchetto 1.1.1 dagli asset di questa release.
I modelli di trascrizione si scaricano separatamente dal Model Manager.
